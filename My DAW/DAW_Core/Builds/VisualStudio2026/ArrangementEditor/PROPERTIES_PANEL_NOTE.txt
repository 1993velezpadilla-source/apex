// This is a standalone version that works without SampleSettings dependency

The ClipPropertiesPanelCore was designed to reuse SampleSettings components,
but since those files don't exist in this workspace, you have two options:

OPTION 1: Skip the properties panel for now
- The arrangement editor works perfectly without it
- Double-click will simply not open a panel
- All editing can be done via direct manipulation (handles, tools)

OPTION 2: Create simplified inline knobs
- Copy the knob/button implementation directly into ClipPropertiesPanel
- Self-contained, no external dependencies
- I can generate this if you want

For now, I recommend OPTION 1 to get the build working.
The core arrangement editor with all tools, rendering, and plugin detection
will work perfectly.

To disable the properties panel dependency in ArrangementViewCore:
- Comment out the m_propertiesWindow instantiation
- Comment out the mouseDoubleClick handler
