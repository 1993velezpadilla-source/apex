OVERVIEW
--------
This replaces all existing Create Sequence files and adds three new
ones. After this update the dialog has:

  • 82 shape modes across 11 categories
  • 7 random-pattern flavors (Melodic, Rhythmic, Glitch, Organic,
    Mathematical, Surprise, Full Chaos)
  • Non-repeating randomization — every random seed is persisted to
    disk so the user literally cannot generate the same pattern twice
    across sessions
  • Pattern Library — save patterns with names; persisted as XML
    under userAppData/APEX/Sequences/  (follows the user across
    projects on the same machine)
  • 8 knobs (added Chaos, Repeat)
  • Library browser popup with live curve thumbnails
  • Dialog grows to 880×660

The PUBLIC API of AutomationSequenceDialogComponent is UNCHANGED:
  • Same constructor signature: (onAccept callback, onCancel callback)
  • Same onAccept payload: (GeneratedCurve, SequenceParams)
  • Same GeneratedCurve.samples[512] for downstream consumers
So MainComponent.cpp and TrackList.h require NO changes.

ARCHITECTURE
------------
Same nucleo discipline as v1/v2:

  Types.h            — POD enums and structs only, no logic
  GeneratorCore.h    — pure static math, 82 shape evaluators
  HistoryCore.h      — message-thread file I/O, seed history + saved
                       patterns. Mutex-guarded. NEVER call from audio
                       thread. Uses inline static singletons (C++17).
  RandomizerCore.h   — 7 random flavors, pulls seeds from HistoryCore
                       so non-repetition is guaranteed.
  LibraryComponent.h — saved-pattern browser, opens in its own
                       DialogWindow. Uses GeneratorCore::generate to
                       render live thumbnails per row.
  DialogComponent.h  — main dialog declarations
  DialogComponent.cpp — main dialog implementations


FILE I/O LOCATIONS (created automatically on first use)
-------------------------------------------------------
  Windows:  C:\Users\<user>\AppData\Roaming\APEX\
              SeedHistory.dat              (binary uint32 list)
              Sequences\<name>.apexseq     (one XML file per pattern)

The folders are auto-created on first save. No installer changes needed.
