APEX G10 — CONCEPTO v2

Este mockup usa audio real (Web Audio API): los faders controlan 10 filtros peaking biquad reales y la curva sale de un AnalyserNode después de los filtros. Boostea 2 kHz y la curva sube de verdad; silencia y la curva cae; BYPASS y la curva se aplana.

📐 Cómo se traduce este concepto a JUCE real (G10SpectrumAnalyzerComponent / G10BandFaderComponent / G10EyeHandleComponent)
Concepto HTMLImplementación JUCE
Curva de trazo + fill + glow (canvas) G10SpectrumAnalyzerComponent::paint(): construir un juce::Path con los 140 puntos log (20 Hz–20 kHz, dBFS 0..-60), path.lineTo() por punto; glow = 3 g.strokePath() con PathStrokeType de ancho 6/3/1.5 y alpha 0.10/0.35/0.9 (sin shadowBlur — barato); fill = cerrar el path a la baseline y g.fillPath() con gradiente vertical maroon→transparente.
Datos reales (AnalyserNode post-filtros) Ya implementado: G10AnalyzerFifo (audio thread) → tick() ~30 Hz (GUI thread) → FFT 2048 → barTargetDb_ → onPresentationTick() (60–144 Hz) suaviza en dB (attack 0.05 s / release 0.40 s) → barLevels_. Solo cambia el render: de fillRect por barra a un Path continuo.
Ojo pequeño (aura 34 / shell 22 / iris 4x5.2 / pupil 1.6 / rune 2.2) G10EyeHandleComponent::paint(): reducir las constantes de geometría (aura 50→34, shell 42→22, iris 6.2x8.2→4x5.2, pupil 2.7→1.6, rune 3.2→2.2) y el setBounds del handle en G10BandFaderComponent::refreshFromParameter() (54→34 px). El blink squash ya existe (scaleY en onPresentationTick).
Track de 2px + fill de ganancia G10BandFaderComponent::paint(): track addRoundedRectangle de 4px→2px; añadir un rect de fill entre 0 dB y el handle con bandCore().withAlpha(0.35f).
Faders arrastrables → filtros reales Ya implementado: mouseDown/Drag/Up → G10Parameter::setValueNotifyingHost → DSP real. El mockup demuestra el mismo contrato con biquads Web Audio.
Blink squash (CSS animation 0.22 s) Ya implementado: startBlink() (scheduler ~7.4 s) → onPresentationTick() anima el squash 220 ms con wall-clock; repaint solo del ojo.
Colores de banda Sin cambios: G10Colors::bandCore/bandHalo (contrato intacto).
Maroon del analyzer Sin cambios: analyzerCore #800000 / analyzerGlow #B03030 / analyzerDeep #4A0000.
